Reading rules & model limits

Broad leadership: both beat SPY. Heavyweight-led: cap beats SPY while equal weight trails. Broadening under the surface: equal weight beats SPY while cap trails. Broad weakness: both trail SPY. Mixed: one or both legs lie within ±0.25% of SPY. These are experimental return classifications, separate from RRG quadrants.

The ratio shows whether participation is expanding beyond heavyweight influence. A rising ratio can also mean equal weight is falling less: inspect both absolute charts before interpreting it as a long setup. Equal-weight ETF performance does not measure the number of advancing stocks.

Returns use adjusted closes; RRG uses the dashboard's existing raw-close 10/16/5/4 approximation. Both RRG legs share SPY; the RSP view is a separate equal-weight market lens. RSPC and RSPG track Plus indices which can include mid-cap constituents. Fund fees, rebalancing and different holdings can affect spreads. Equal-weight RRGs have integrity checks but no independent EdgeRater coordinate calibration yet.

Data refreshes through the dashboard's existing cloud workflow; this page checks for new data every five minutes while open. Only completed daily sessions are included. Missing/stale data clears classifications and displays a feed warning.
