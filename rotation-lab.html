Linear Rotation Map

Inspired by the leaders/laggards concept, but built with transparent formulas. It is intentionally separate from the RRG and Swing Journal until we decide whether it adds real trading value.

Experimental methodology: X = total return over the chosen window minus SPY return over the same window. Y = recent relative return minus the immediately preceding relative-return window of the same length. Positive Y therefore means relative performance is accelerating; negative Y means it is decelerating. This is not Andrew Rader's proprietary momentum metric and does not claim to measure dealer gamma.

Heuristic Playbook

Phase 1 watch: stretched positive X with negative Y — leaders beginning to fade.

Phase 2 watch: strongly negative X and negative Y — laggards still capitulating.

Rotation reversal: negative X but strongly positive Y — lag-to-lead candidates worth deeper review.

These are screening heuristics, not automatic trade signals.
