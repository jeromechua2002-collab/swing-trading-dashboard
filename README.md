# Swing Trading Dashboard

Free hosted TradingView dashboard for embedding inside the Notion swing-trading journal.

## Widgets
- Broad market: SPY, QQQ, IWM, DIA
- Growth: XLK, XLY, XLC, SOXX
- Rotation: XLU, XLRE, XLP, XLI, XLB, XLF, XLV, XLE
- Macro: VIX, DXY, US 2Y / 10Y / 30Y
- Detailed 1-hour QQQ and SOXX charts

## Notion
This dashboard is externally hosted, so it does not consume Notion's native chart allowance.
